# Code of Conduct

## Our standard

Be professional and assume good faith. We follow the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
in spirit: no harassment, no personal attacks, no publishing others' private
information.

## Enforcement

Problems get handled by the maintainer (@epicsagas) — usually a warning,
escalating to a ban for repeat or severe cases. Report via a private GitHub
message or security advisory.
